## METRICS
  activeUsers:	Количество активных пользователей (те, кто взаимодействовал с сайтом)
  newUsers:	Новые пользователи, впервые посетившие сайт
  sessions:	Количество сессий (одно посещение от начала до конца)
  averageSessionDuration:	Средняя длительность сессии
  engagementRate:	Уровень вовлечённости (доля сессий, где пользователь провёл 10+ сек или совершил событие)


## dimensions
  sessionSource:	Источник (Google, Facebook, Direct и т. д.)
  sessionMedium:	Тип трафика (organic, referral, cpc, email и т. д.)
  sessionCampaignNam:	Кампания, по которой пришли (если есть UTM-метки)
  pageReferrer:	Конкретный сайт, откуда пришёл пользователь ?
  date: дата
